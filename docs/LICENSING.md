## Obligations and how they are met

- **AGPL-3.0 (the app, because of MuPDF).** The complete corresponding source of each release is
  published with it: `tools/export_public_source.py` exports the exact committed tree that the
  release was built from (an allowlist; private history, audit records and reference material are
  never included) and the release builds are made from that archive
  (`tools/build_from_archive.sh` / `.ps1`). The About dialog shows the source URL. Since the app
  has no network service, the AGPL's network clause has no extra effect.
- **LGPL-3.0 (Qt, PySide6, libheif, libde265).** Linked dynamically, shipped as separate library
  files that a user can replace; licence texts and the source offer ship with the app;
  `tools/fetch_third_party_sources.py` gathers the exact upstream sources for the release.
- **LGPL-2.1 (libfuse in the AppImage runtime).** The runtime is static, so the release points to the
  runtime's complete source at its release tag (which builds libfuse and squashfuse from pinned
  sources), allowing a user to rebuild and relink it. Listed in the release checklist.
- **GPL-2.0-or-later (x265 in pillow-heif).** Its source is published with the release
  (`packaging/licenses/SOURCES.json` records the exact archive and hash); the app as a whole is
  AGPL-3.0-or-later, which is compatible.
- **Apache-2.0 (OpenCV, ONNX, Tesseract data).** Licence and NOTICE texts ship unchanged. The
  Universal edition's OpenCV is a modified build (fewer modules, one packaging patch); the patch is in
  `packaging/opencv/` and the build script states what changed.

## Not bundled

- No trained AI model. Optional model packs are installed by the user from local files and carry their
  own licence, which the app shows and hash-checks (`docs/image-ai-model-packs.md`); review a model's
  weights licence before distributing a pack.
- No LibreOffice, PowerPoint, Office or Ghostscript: the app uses LibreOffice only if the user has it.
- No fonts beyond those inside Qt and MuPDF.

## Trademarks and provenance

The ENG Drawing Viewer name and its blue icon identify this project. The public source contains no
corporate material, employer configuration or machine-specific paths; `tools/export_public_source.py`
and `tools/check_bundle.py` scan for personal paths, e-mail addresses, keys and the owner's private
terms (kept outside the repository) before anything is shared. Open audit items are tracked in the
release checklist.

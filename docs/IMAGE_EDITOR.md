# Image Editor implementation

The integrated Image Editor keeps RGBA layers, masks, layer offsets and editable MARK-style annotations in versioned `.engimg` projects. Full-resolution compositing supports normal, multiply, screen and overlay. Crop preserves off-canvas layer data; resizing, rotation, flip, canvas size, paint, erasure/restoration, clone, healing, selections and mask refinement have bounded undo history. Workers handle expensive pixel tools; failures restore the pre-operation state.

Copy to Clipboard opens PNG/JPEG/TIFF/BMP settings with quality, dimensions, DPI, full-image/selection and alpha/background controls. Remembered settings can be reopened from the adjacent menu or Preferences. macOS publishes the selected native pasteboard type plus interoperable representations; Windows uses registered formats, CF_TIFF where relevant, DIBV5 and legacy DIB. Receiving applications choose their preferred representation. JPEG uses the chosen opaque background. Native macOS pasteboard encoding is tested; actual Office paste and Windows clipboard execution still require platform testing. Copy does not alter editable layers.

Export measures actual encoded bytes and can search quality and optionally reduce dimensions to meet a size target. PNG/JPEG/TIFF/WebP/BMP/GIF/AVIF/HEIF codecs were exercised in the Intel frozen smoke run. Formats have different alpha, animation and colour limitations; export is a composite, not a layered interchange file. Keep the `.engimg` project. ICC metadata preservation is not a complete colour-managed editing pipeline.

Optional subject selection uses a user-selected, hash-verified local ONNX pack. No download, account or runtime network is needed. The optional BiRefNet FP32 pack was measured separately on this Intel Mac: 12.83 seconds model load, 9.78 seconds first inference, 6.77–6.85 seconds warm inference and about 9.82 GB peak process RSS. Three synthetic mask IoUs were 0.776–0.829. These are limited fixtures, not proof of professional matting quality. CoreML/DirectML performance is unverified. See image-ai-model-packs.md for the manifest contract.

Current limits: 80 megapixels per image/layer, 64 layers, bounded archive assets and 256 MiB history. Large edits can exhaust undo retention. Rendering is not tiled and some operations remain synchronous. Advanced frequency separation, liquify, RAW development, advanced typography and Photoshop feature parity are not implemented.

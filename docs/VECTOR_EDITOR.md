# Vector Editor and offline tracing

The workspace stores editable millimetre geometry: lines, quadratic/cubic Bézier paths, shapes and text. It supports selection, node/handle edits, pen drawing, move/rotate/scale/duplicate/group/order, visible/locked layers, fill/stroke/opacity, booleans (union/difference/intersection/exclusion), outlining text, and path simplification. Grid snapping, draggable ruler guides and mm/cm/in ruler units aid placement. Calibration scales the entire drawing from a selected known width. Numeric geometry properties remain labelled in millimetres.

Save `.engvec` to preserve the editor's layers, guides and editable objects. SVG import/export supports a bounded subset of path/shape/text geometry and transforms; unsupported effects are reported. This is not full SVG browser fidelity. DXF import uses ezdxf for supported entities and declared units; missing units produce a warning. DXF curve export tessellates editable geometry, so inspect tolerance and round-trip dimensions. SVG, DXF, PDF and PNG export are available. DWG is unsupported.

Import a raster image, then choose Trace. The dialog compares the original with a vector preview and offers laser cutting, laser engraving, vinyl cutting, CAD import and illustration presets. Threshold, colour quantization, edge detection, corner-connected background removal, noise area, smoothing and simplification run locally. Preview analysis is bounded to 700 pixels and final analysis to 2400; the output records boundary uncertainty. Source DPI establishes an initial physical size, not verified scale. Calibrate before manufacturing. Edge mode traces bands, not centrelines, and can create double contours. Output paths are editable geometry, not embedded raster images.

Cutting checks report open, duplicate, degenerate and intersecting contours. Intersection checking has explicit segment/comparison limits and reports incomplete checks. Curves are approximated for checking. No result certifies production readiness; inspect geometry, kerf, material and machine requirements. General photographs may trace poorly. There is no toolpath/G-code generation or automatic reconstruction of CAD design intent.

Implementation uses Qt paths, OpenCV contours and ezdxf. No Inkscape, LibreCAD or Potrace source is incorporated. See VECTOR_RESEARCH.md for primary-source research and licensing distinctions.
